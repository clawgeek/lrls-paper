## 备注（发之前确认）

- 如果组委会回复“initial submission 不需要 PDF eXpress”，那就是 EDAS 的检查项配置得比 CFP 严，
  按他们的说明处理即可，可能需要在 EDAS 里换一个 track 或联系 EDAS 支持。
- 如果给了 Conference ID，流程是：进 https://ieee-pdf-express.org → "New User" 用邮箱注册 →
  输入 Conference ID 绑定 → 上传 `paper/cec/cec-v1.pdf` → 选 "PDF Check" 或 "Conversion" →
  下载返回的认证 PDF → 重传到 `edas.info/uploadPaper.php?m=1571382688`。
- 认证后的 PDF 会被 PDF eXpress 写入自己的元数据标记，这正是 EDAS 检查的东西。
